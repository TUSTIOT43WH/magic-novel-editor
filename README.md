# 魔境小说编辑器

一个面向中文长篇小说创作的本地优先编辑器，支持多书籍、章节写作、Vibe 续写、知识库召回、人物档案、人物关系、时间线、写作 Skills 和可配置的大模型接口。用户可以在设置页面编写提示词。在知识库里编写相关设定，在写作台中决定是否引用这些设定一并发给大模型，也可以编写自己的作家skills。

## 环境要求

- Node.js 22.13.0 或更高版本
- npm

## 本地启动

```bash
npm install
npm run dev
```

根据终端提示打开本地地址，通常为 `http://localhost:3000`。

## 模型配置

在编辑器的“设置 → 模型连接”中填写兼容 OpenAI Chat Completions 或 Responses API 的地址、API Key 和模型名称。也可以复制 `.env.example` 为 `.env`，然后填写服务端环境变量。

不要把 `.env`、API Key、本地数据库、构建产物或浏览器数据提交到 Git 仓库。

DeepSeek 可使用完整地址 `https://api.deepseek.com/chat/completions`，模型名称按服务商文档填写（图文生成可选支持图片的 `deepseek-flash`）。当前程序未实现 Anthropic 协议，不要在本程序中填写 `/anthropic` 基础地址。

## 图片与文字生成故事

在写作台 Vibe 输入框下方点击“上传图片”，填写文字描述后点击“生成草稿”。可以用“图1中的人物”“图2的场景”等说明图片的用途。

- 支持 PNG、JPEG、WebP，最多 4 张，每张不超过 5 MB；可预览、移除。
- 图片和文字、选中的上下文一起发送给配置的模型，需要模型与接口支持图片输入。
- 图片仅按书籍和章节在本页内存中暂存，刷新后需重新选择；选择图片本身不会调用模型。
- 原有纯文字写作和流式正文输出继续可用。

## AI 优化章节召回

在写作台右侧“本章召回总结”区域点击“AI 优化总结”，模型会读取本章完整正文与章节信息，按时间、地点、主要角色、关系变化、关键事件、章末状态和未解决事项生成总结。此操作不附带 Vibe、知识库或其他章节。

新总结自动保存并锁定，后续章节召回使用新版总结；作者仍可手动编辑或解除锁定。时间线按章节顺序排列，并完整显示自定义时间。

## 常用命令

```bash
npm run dev
npm run build
npm run start
npm run lint
node --test tests/story-images.test.mjs
```

首次启动时书库为空，仅包含一章空白章节；所有小说正文、人物、关系、知识库和时间线均由使用者自行创建。
