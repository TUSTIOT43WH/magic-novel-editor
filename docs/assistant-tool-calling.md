# 提问助手：按需查书与独立历史会话

## 方案评估与调整

保留七个只读工具、浏览器本地检索、有限工具循环，不新增依赖，不修改数据库结构。工具只能读取当前书的请求开始时快照，不能修改小说、文件或访问网络。

- 按作者最新要求改为真正的流式输出，不采用原方案的非流式工具轮，也不会为了打字效果额外请求一次答案。上游若本身只返回 JSON，则该次只能整段显示。
- 不把“没有调用工具”视为能力故障：通识问答通常不需要工具；书内问题未查证时显示提示，不伪装成已经读过原文。
- 只对明确的工具不支持错误降级，不隐藏 API 地址错误、模型名错误、认证失败、限流。
- 未命中只表示本次未查到，不能据此断言全书不存在。
- 保留较早工具结果，后续查询使用剩余预算；不回溯篡改先前引用证据。

## 请求与预算

作者主动发送问题才请求模型。系统提示词、最多六条近期有效历史、当前问题组成真正的 messages 数组，不再拼成历史文本。关闭查书仍保留通用问答历史，但不重发被标记为来自本书的助手回答。

“允许查阅本书”打开时提供七个函数定义：search_chapters、read_chapter、get_character、get_relations、get_timeline、search_knowledge、get_outline。强书内信号命中时可预取最多三条相关召回片段、最多2000字符；不直接发送整本小说。模型选择工具后，浏览器只回填限量结果。

- 最多三轮工具执行、四次模型请求（降级重试也计入请求数）。
- 每轮最多八个工具调用；每个结果不超过4000字符，通常为3500字符。
- 预取与工具结果合计不超过12000字符；历史不计入此资料预算，最近每条历史最多8000字符。
- read_chapter 支持 offset/maxChars 分页，不一次读取整章；缺少总结时明确告知，不伪造总结。
- 单次模型请求最多三分钟。停止、切换书籍或切换会话会取消正在进行的请求；保留已收到的部分。取消无法撤回已发送资料或已产生的上游计费。
- 首轮到末轮都流式解析正文及 tool_calls 增量；为支持兼容服务，工具轮 reasoning_content 原样回传，但不显示、不存入会话历史。DeepSeek 官方域名下本助手关闭思考模式以减少等待。

Responses 端点第一版不启用工具；明确提示并使用普通流式问答，书内问题仅带有限预取/检索片段。工具降级不是联网搜索。

## 历史会话

会话放在每本书的 assistant 字段，随原有 workspace 整库保存，无数据库迁移、无模型密钥写入会话。两处入口（悬浮窗与完整智能体页）共享同一份状态。

可新建、选择、改名和删除会话，也可删除某条问题及其后续问答。修改历史问题后替换该问题和旧回答，并移除依赖旧上下文的后续问答；有后续内容时先确认。删除不可撤销。

点击助手顶部会话标题打开历史列表，可在本地搜索标题或问答内容；列表显示创建日期、提问次数及当前会话。重命名、删除问答/会话、覆盖后续对话均采用统一的居中弹窗，支持 Esc 关闭和键盘操作，删除默认聚焦取消按钮。搜索不会触发模型请求。

默认标题在本地依据第一问提炼（去掉常见提问前缀、取首句主题并限制长度），不额外花 Token。修改第一问时会更新自动标题；作者手动改名后不会被覆盖。

## 文件与验证

- app/lib/assistant-tools.ts：只读工具、参数约束、预算和本地书内意图识别。
- app/lib/assistant-gateway.ts：独立助手流式代理、兼容错误、断流与取消处理。
- app/lib/assistant-client.ts：消息历史、工具执行循环、来源与降级提示。
- app/lib/assistant-types.ts：协议与持久化类型。
- app/components/assistant-panel.tsx：会话控制器、历史操作、流式显示。
- app/page.tsx、app/globals.css：接入两处入口及样式。write/audit/summary 的模型逻辑不变。

运行：node --test tests/assistant.test.mjs tests/story-images.test.mjs。

可选浏览器验收：设置 PLAYWRIGHT_MODULE 为现有 playwright 模块路径，然后运行 node --test tests/assistant-ui.test.mjs。复用 localhost:3000（可用 ASSISTANT_TEST_URL 改地址），不会启动第二个开发服务器。测试完全模拟模型和书库，不接触真实小说或密钥。

已用模拟服务验证：书内受伤问题调用章节检索并显示章节来源；唐朝年号问题仅一次请求、无查书来源；查询不存在的唐朝设定得到明确的本次未命中结果。模型实际工具选择和回答质量取决于作者配置的模型，未使用真实模型做付费测试。

另有浏览器验收覆盖真实增量渲染、停止、修改覆盖、标题改名、问答/会话删除、书籍隔离、重新加载持久化、生成中切书和小屏悬浮窗。既有全库类型检查17条错误及 page.tsx 两条 effect lint 错误保持原数量；新模块独立 lint 通过。
